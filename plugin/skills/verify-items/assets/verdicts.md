# <issue番号> 再検証の記録

`##` の見出しは、その再検証が走った時点のコミット。1回の再検証が1つのラウンドになり、新しいラウンドを末尾に足す。最後のラウンドが最新で、それより前のラウンドは当時のコードに対する記録として読む。

項目番号は同じ論理的な項目を表す。対象コード、主張、証拠はコードの更新で変化しうるため、ラウンドにコミットを持たせ、古いラウンドの評決を現在状態への評決として読まないようにする。

削除した項目の主張と、リスク度が下がった経緯は、このファイルにしか残らない。report.tsv と findings は現在の状態だけを持つ。
